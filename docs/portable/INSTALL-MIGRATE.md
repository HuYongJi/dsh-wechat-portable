# 安装、跨设备迁移与回退

## 两类交付物

- `dsh-wechat-portable-0.1.0-alpha.4.tgz`：本地插件安装包，含已编译 Host/Client、普通二维码运行依赖、许可和说明。
- `dsh-wechat-portable-0.1.0-alpha.4-source.zip`：可继续开发的源码快照，含锁文件、测试和 Node 构建脚本；不含 node_modules、构建缓存、Git 历史或个人状态。

包可复制给其他人，不需要保留原开发目录名、盘符或账号。目标设备必须另有 DSH 0.2.0-rc.2。不要根据“可迁移”推断整个 DSH、模型或微信授权也被打包。

## 安装顺序

1. 使用操作系统内置 SHA-256 工具核对分发的校验值。
2. 停止旧桥接；备份现有 DSH 插件配置。不同设备上也不要让同一个微信 bot 被多个守护进程同时轮询。
3. 在 DSH 插件管理中选择本地来源，导入 tarball。具体本地来源入口以该 DSH 版本实际界面/帮助为准。不要修改应用安装目录、替换 app.asar 或添加版本豁免。
4. 重新加载/重启 DSH；找到“微信桥接（Portable）”设置。
5. 选本机已有专用目录。不要选择文件系统根目录、个人整个主目录、密钥/凭据目录或共享盘。
6. 本机扫码，微信内确认；检查模型、工作目录、权限设置后手动启动。
7. 使用 VALIDATION.md 中的人工步骤验收后再处理真实任务。

若原生设置界面不可用，应保持停用并收集不含秘密的错误概述，不应开放回环管理端口到局域网或回退为绕过权限的接口。

## 安全迁移

在旧设备停止桥接后，只导出白名单普通偏好：

```text
node lib/portable/cli.js export ./settings.json --profile desktop
```

新设备安装相同插件，创建专用工作目录，先预览再确认：

```text
node lib/portable/cli.js import ./settings.json --profile desktop --workspace "本机工作目录绝对路径"
node lib/portable/cli.js import ./settings.json --profile desktop --workspace "本机工作目录绝对路径" --confirm
```

自定义 `dataDir` 时所有命令追加同一个 `--data-dir "绝对本地路径"`。导入只写普通配置，不安装、不拉起进程、不改变宿主权限、不改系统 ACL。任何运行标记存在时都会拒绝实际导入；不要为了通过检查而删除活进程标记。

新设备必须重新选模型、重新扫码。不会迁移账号、token、信任集、已有会话、提示词、路径、附件、二维码、端口或 PID。旧设备授权不会因导出/导入而自动撤销；单独停止/解绑它。

已确认的扫码授权不能通过关闭本机面板撤销；正在完成的确认请求可能已保存授权。确认后依然不会自动启动。需要撤销时在微信侧管理授权并停止插件。

## 状态与清理

默认按 profile 隔离在 `DSH_PROFILE_DIR/wechat-portable`；否则为 `DSH_HOME/profiles/<profile>/wechat-portable`。不使用上游的全局 `wechat-bridge` 目录，不自动搬运原版账号或历史。

状态中包含敏感授权与消息。不要把整个目录打 ZIP 分享，不要放进 Git、共享盘或公开备份。Windows 用当前用户继承 ACL；其他平台目录/文件分别为 0700/0600。不以 chmod 代替 Windows ACL 验证。

收到的附件最多占用 256 MiB，达到上限会拒绝新附件。停止桥接后本地核对附件目录，再由使用者自行清理；程序不会任意递归删除文件。附件在私有状态目录内，DSH 读取它可能仍需要一次授权，不会为了便利自动拓宽 sandbox。

若发现归属不明的活 PID，程序拒绝启动第二份轮询，也不会杀这个 PID。请关闭旧宿主，必要时重启设备；不要照抄 PID 到 kill 命令。导入/分享绝不携带这些标记。

## 停用 / 回退

先停止桥接，再从 DSH 禁用/卸载本包，按宿主提示重启。必要时还原之前备份的 DSH 配置。卸载不删除用户数据；确认无须保留后由用户在本机自行清理。不要同时启用本版和原版。

alpha.1/alpha.2 已经用户授权安装；alpha.3 修复独立 TLS 取码、响应兼容与可见诊断。更新前备份，完成后完全退出并重新打开 DSH；当前 alpha.4 进一步修复微信 Agent 初始化的服务作用域访问；重启后标题应显示 Alpha.4，随后手动启动桥接。保留原绑定和会话，不需要重新扫码。旧包保留，不会自动覆盖其他设备。

首次使用时，输入框中的建议目录可能尚未存在。请先创建专用空目录，或选已有目录，再保存；不会自动授予 Agent 文件/网络权限。若微信要求额外手机配对码或登录节点切换，本预览版会给出明确提示并停止，该分支仍需后续适配。不要把二维码或配对码发送到聊天中。
